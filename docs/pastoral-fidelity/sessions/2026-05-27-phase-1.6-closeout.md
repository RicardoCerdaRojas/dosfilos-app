## Retrospective

**Qué fue mejor que estimado.** La reutilización de Fase 2 (WitnessOrchestrator + escalado puro) hizo el two-tier barato: el tripwire inline fue parametrizar el callable existente, no un motor nuevo. El rename masivo `syntax`/`morphology`, que parecía riesgoso por blast radius, lo contuvo el compilador — distinguir refs del seed de las del greek-tutor/canonical-analyzer (mismas palabras, otro dominio) fue el 80% del cuidado, y typecheck por paquete cazó todo.

**Qué tomó más tiempo.** El cierre, no el código. El deploy falló por una secuencia mala: se deployaron las funciones manualmente (para correr la migración) antes de pushear/mergear el código, y el PR #264 subió solo docs — el feat quedó en commit local. Resolverlo pidió branch nuevo + rebase sobre main (sacar el commit docs duplicado que main ya tenía squashed). Lección concreta abajo.

**Qué cambió del plan original.** Dos cosas. (1) El género: el plan (ADR-024) pedía reutilizar `BookPanorama` (LLM); se shipeó un mapa determinista para mantenerlo funcional sin cablear el pipeline expositivo multi-pase a una sola perícopa — desviación documentada, no silenciosa. (2) Apareció una directiva nueva del fundador a mitad de smoke: tutor socrático contextual por paso (no solo doctrinal), que reabre la política de silencio de ADR-023. Se decidió NO meterlo en 1.6 y aterrizarlo en Fase 2.5 con ADR propio.

**Aprendizajes para fases futuras.** (1) **Pushear/PR el código ANTES de deployar funciones manualmente** — si el proyecto live tiene funciones que main no tiene en source, el deploy CI aborta para no borrarlas. (2) **Pages `.tsx` no importan `firebase/functions`** (hard violation del pre-commit) — los callables van por un service en `@dosfilos/application`; tenerlo presente al crear componentes nuevos que llaman callables. (3) Cuando una idea del fundador reabre una decisión de ADR, no parchearla en la fase activa: capturarla en el phase doc destino + ADR nuevo. (4) Las desviaciones funcionales (mapa determinista vs LLM) son legítimas si se documentan como deuda visible y no se marcan criterios como `[x]` cuando son `[~]`.
