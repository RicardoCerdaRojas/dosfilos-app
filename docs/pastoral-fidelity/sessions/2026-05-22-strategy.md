# Sesión 2026-05-22 — Kickoff Pastoral Fidelity Initiative

## Resumen

Sesión de estrategia + arquitectura. Definición del marco completo de la iniciativa, decisiones fundacionales, y creación del skeleton documental profesional para sostener el trabajo a lo largo de 7 fases.

## Decisiones tomadas

1. **Pivote del producto** confirmado: de fábrica de sermones a plataforma de formación pastoral.
2. **Tres principios no-negociables** establecidos: P1 Labor antes que output (Esdras), P2 AI desarrolla, no origina (Brooks), P3 Confrontación obligatoria (Hechos 20:27).
3. **Mecanismo de tres testigos** para validación: contexto inmediato + paralelos canónicos + confesión declarada por el propio pastor.
4. **Six-step spine** del tutor griego/hebreo como gate obligatorio del Step 1 del wizard.
5. **Proyecto como unidad raíz**, sermón/estudio/newsletter/post como artefactos derivados.
6. **Diferir exégesis a Fase 7** con desacople sermón↔paper.
7. **Estructura documental profesional**: in-repo + memoria pointer + CLAUDE.md.
