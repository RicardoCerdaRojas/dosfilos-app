# **1\) ¿QUÉ ES EL “CÓDIGO DE COLORES”?**

El “código de colores” es un sistema pedagógico que:

👉 **Asigna un color a cada parte del verbo**

* Prefijos  
* Vocales características  
* Radicales (raíz)  
* Sufijos

👉 Para que puedas:

* **Ver patrones**  
* **Reconocer el binyan sin pensar demasiado**  
* Identificar raíz \+ forma rápidamente

---

## **Idea clave**

El hebreo no se memoriza solo con tablas…  
 👉 **Se reconoce por patrones visuales repetidos**

---

# **2\) ESTRUCTURA QUE EL COLOR REPRESENTA**

Todo verbo hebreo tiene esta lógica:

**(Prefijo) \+ R1 \+ R2 \+ R3 \+ (sufijos)**

El código de colores separa:

| Elemento | Función |
| ----- | ----- |
| Prefijo | indica binyan / tiempo |
| Vocal 1 | clave del binyan |
| Radicales | significado base |
| Vocal 2 | patrón interno |
| Dagesh | intensificación (Piel, etc.) |

---

# **3\) LOS 7 BINYANIM Y SU “HUELLA VISUAL”**

Ahora lo importante: **cómo el color te ayuda a distinguirlos**

---

## **1\. QAL (קַל) — “simple”**

### **Patrón:**

* No tiene prefijo  
* Vocales simples

### **Ejemplo:**

כָּתַב (katav) – “él escribió”

### **Cómo lo ves:**

* Sin prefijos raros  
* Sin dagesh fuerte  
* Forma básica

👉 **Color mental:** neutro (base)

---

## **2\. NIFAL (נִפְעַל) — pasivo/reflexivo**

### **Clave visual:**

* Prefijo **נִ (ni-)**

### **Ejemplo:**

נִכְתַּב – “fue escrito”

### **Código de colores:**

* Prefijo \= color distintivo (ej. verde)  
* Raíz intacta

👉 Si ves **נ \+ hireq**, sospecha Nifal

---

## **3\. PIEL (פִּעֵל) — intensivo**

### **Clave:**

* **Dagesh fuerte en la 2ª radical**  
* Vocal i-e

### **Ejemplo:**

דִּבֵּר – “habló intensivamente”

### **Visual:**

* Centro “engrosado” (dagesh)

👉 Esto coincide con lo que viste en daguesh:

duplica la consonante

---

## **4\. PUAL (פֻּעַל) — pasivo de Piel**

### **Clave:**

* Igual que Piel pero con vocales pasivas

### **Ejemplo:**

דֻּבַּר – “fue hablado”

👉 Visualmente:

* Dagesh fuerte ✔  
* Vocales distintas

---

## **5\. HITPAEL (הִתְפַּעֵל) — reflexivo**

### **Clave principal:**

* Prefijo **הִתְ**

### **Ejemplo:**

הִתְקַדֵּשׁ – “se santificó”

### **Código de colores:**

* Prefijo destacado  
* Dagesh en R2

👉 Confirmado en tu material:

* “preformativo הִת”

---

## **6\. HIFIL (הִפְעִיל) — causativo activo**

### **Clave:**

* Prefijo **הִ**  
* Vocal i característica

### **Ejemplo:**

הִכְתִּיב – “hizo escribir”

---

## **7\. HOFAL (הָפְעַל) — causativo pasivo**

### **Clave:**

* Prefijo ה con vocal o/u (qamets hatuf o qibbuts)

### **Ejemplo:**

הָכְתַּב – “fue hecho escribir”

👉 Tu material dice:

* “prefijo ה \+ qamets hatuf”

---

# **4\) ¿CÓMO FUNCIONA EL CÓDIGO DE COLORES EN LA PRÁCTICA?**

El "Código de Colores" se basa en la tabla fonética de vocales para que identifiques el patrón principal que te revelará el Binyan:

| Clase Fonética | Color | Vocales |
| ----- | ----- | ----- |
| **Clase A** | 🔴 Rojo | Pataj, Qamets |
| **Clase E/I** | 🟢 Verde | Segol, Tsere, Jireq, Jireq yod |
| **Clase O/U** | 🟠 Naranja | Qamets jatuf, Jolem, Qibbuts, Shureq |
| **Shevá / Reducidas** | 🟣 Púrpura | Shevá, Jatef pataj, Jatef segol, Jatef qamets |

👉 Resultado:  
Al observar las vocales preformativas o temáticas del verbo, el estudiante "tira los colores" para ver de qué clase son y deduce automáticamente a qué Binyan pertenece.

# **5\) CÓMO USARLO PARA RECONOCER BINYANIM**

## **PASO A PASO (método clave)**

### **1\. ¿Hay prefijo?**

| Prefijo | Binyan probable |
| ----- | ----- |
| נ | Nifal |
| הִ | Hifil |
| הָ / הֻ | Hofal |
| הִתְ | Hitpael |

---

### **2\. ¿Hay dagesh en la 2ª radical?**

✔ Sí → Piel / Pual / Hitpael  
 ❌ No → Qal / Nifal / Hifil / Hofal

---

### **3\. ¿Qué vocal domina?**

* i → Hifil / Piel  
* u/o → Hofal / Pual  
* simple → Qal

---

# **6\) CONEXIÓN CON TU MATERIAL**

Tu gramática ya te dio las piezas:

* Dagesh \= duplicación  
* Prefijos \= claves estructurales  
* Vocales \= patrón interno

👉 El código de colores **solo organiza visualmente todo eso**

---

# **7\) RESUMEN ULTRA CLARO**

👉 El código de colores sirve para:

1. Separar partes del verbo  
2. Identificar prefijos rápidamente  
3. Detectar dagesh (clave para Piel)  
4. Ver patrones sin memorizar tablas

# **8\) EJERCICIO (muy importante)**

Identifica el binyan:

1. נִשְׁמַר  
2. הִכְתִּיב  
3. דִּבֵּר  
4. הִתְקַדֵּשׁ  
5. כָּתַב

---

## **Soluciones:**

1. Nifal → prefijo נ  
2. Hifil → prefijo הִ  
3. Piel → dagesh en R2  
4. Hitpael → הִתְ  
5. Qal → forma simple
