# Guía para Generación de Bosquejos Detallados

> **Última actualización:** 2025-12-11  
> **Mantenedor:** Ricardo Cerda  
> **Propósito:** Definir estructura y criterios para bosquejos practicos y predicables

---

## 🎯 Definición de Bosquejo Homilético

El bosquejo es la **estructura lógica que desarrolla la proposición** en puntos progresivos y predicables.

---

## 📐 Estructura Requerida

### **Cantidad de Puntos**
- **Mínimo:** 2 puntos
- **Óptimo:** 3 puntos
- **Máximo:** 4 puntos
- ⚠️ Más de 4 puntos hace el sermón difícil de seguir

### **Cada Punto Debe Tener:**

#### **1. Título Impactante**
- Formato: "I. [Título]", "II. [Título]", etc.
- 5-12 palabras
- Memorable y predicable
- En el TONO del enfoque
- Que adelante el contenido

**Ejemplos:**
- ✅ "I. La Humillación Voluntaria de Cristo: Modelo para Nuestra Unidad"
- ✅ "II. El Camino hacia Abajo: La Kenosis como Patrón de Vida"
- ❌ "I. Cristo se humilló" (muy genérico)
- ❌ "I. Juan 1:1" (no es título, es referencia)

#### **2. Descripción Detallada**
- 2-3 oraciones (40-80 palabras)
- Explica QUÉ se va a predicar en ese punto
- CÓMO se desarrolla desde el texto
- POR QUÉ importa para la audiencia

**Ejemplo:**
```
"Comprendemos que la vida cristiana no está exenta de dificultades, 
desánimo y oposición. En medio de estas pruebas, Pablo nos exhorta 
a cultivar una mentalidad de unidad y humildad, no buscando nuestro 
propio interés, sino el de los demás, preparando nuestros corazones 
para el ejemplo supremo que nos da Jesús."
```

#### **3. Referencias Bíblicas**
- **Mínimo 2 referencias** por punto
- Incluir:
  - El pasaje principal
  - 1-2 textos de apoyo/paralelos

**Formato:**
```json
"scriptureReferences": [
  "Filipenses 2:1-4",
  "Romanos 12:3-5",
  "1 Corintios 12:25-26"
]
```

## 🔄 Flujo Lógico del Bosquejo

### **🌟 CRÍTICO: Para Enfoques EXPOSITIVOS**

**Si la proposición usa Estructura Sustantivada (8 elementos), los títulos DEBEN sincronizarse perfectamente.**

#### **Regla de Oro:**
```
Proposición dice: "[número] [sustantivo plural] que [llamado acción]"
                         ↓
Títulos reflejan:    TODOS en armonía con esos elementos
```

#### **Proceso de Sincronización:**

**PASO 1:** Extraer de la proposición:
- ¿Cuántos puntos? (el NÚMERO)
- ¿Qué tipo? (el SUSTANTIVO PLURAL)
- ¿Con qué propósito? (el LLAMADO A ACCIÓN)

**PASO 2:** Generar títulos que TODOS:
- Sean del mismo tipo que el sustantivo
- Expresen el llamado a acción
- Mantengan paralelismo gramatical

**PASO 3:** Verificar armonía:
- ¿Se pueden leer como una lista cohesiva?
- ¿Ninguno "desentona"?
- ¿Fluyen naturalmente?

#### **Matriz de Sincronización (Expositivo):**

| Proposición dice | Tipo de Sustantivo | Los Títulos deben | Ejemplo |
|------------------|-------------------|-------------------|---------|
| "tres **verdades** que debes..." | Doctrinal | Declarar verdades con imperativo | "I. **Debes** reconocer..." |
| "cuatro **motivos** para confiar" | Persuasivo | Dar razones de confianza | "I. La fidelidad **te motiva a confiar**" |
| "tres **pasos** para crecer" | Procesal | Ser secuenciales | "I. **Primer paso:** Reconoce..." |
| "dos **promesas** que aseguran" | Consolador | Declarar garantías | "I. Dios **promete** nunca dejarte" |
| "cuatro **exhortaciones** que transforman" | Imperativo | Ser llamados a acción | "I. **Abraza** la mentalidad..." |
| "tres **principios** para aplicar" | Práctico | Ser aplicables | "I. **Principio 1:** La humildad precede..." |
| "dos **lecciones** para aprender" | Educativo | Enseñar algo | "I. **Lección 1:** El orgullo destruye..." |

#### **Ejemplos Completos Sincronizados:**

##### **Ejemplo A: "verdades que debes obedecer"**
```
Proposición:
"En Mateo 28:19-20, encontrarás tres verdades que debes obedecer 
y que asegurarán que vivimos por la gloria de Dios."

Bosquejo:
I. Debes ir y predicar el evangelio a todas las naciones
   - Imperativo alineado con "debes"
   
II. Debes hacer discípulos, no solo convertidos
   - Imperativo alineado con "debes"
   
III. Debes reconocer la presencia permanente de Cristo
   - Imperativo alineado con "debes"
```
✅ Armonía perfecta: Todos empiezan con "Debes"

##### **Ejemplo B: "motivos para confiar"**
```
Proposición:
"En Romanos 8, descubrirás cuatro motivos para confiar plenamente 
en Dios, aun en medio del sufrimiento."

Bosquejo:
I. El Espíritu Santo te capacita para confiar en la adopción divina
   - "te capacita para confiar" conecta con "motivos para confiar"
   
II. Nada puede separarte del amor de Cristo: Tu razón suprema de confianza
   - "razón de confianza" conecta con "motivos"
   
III. Dios usa todo para tu bien: El fundamento inquebrantable de tu confianza
   - "fundamento de confianza" conecta con "motivos"
   
IV. Cristo intercede por ti: La garantía eterna que asegura tu confianza
   - "garantía... confianza" conecta con "motivos"
```
✅ Armonía: Todos mencionan o implican "confiar/confianza"

##### **Ejemplo C: "pasos secuenciales"**
```
Proposición:
"En Filipenses 2:12-13, recibirás tres pasos progresivos 
para crecer en santidad por el poder de Dios."

Bosquejo:
I. Primer paso: Reconoce tu incapacidad y necesidad de Dios
   - Estructura secuencial explícita
   
II. Segundo paso: Obedece activamente con temor y temblor
   - Continúa secuencia
   
III. Tercer paso: Confía que Dios opera en ti el querer y el hacer
   - Finaliza secuencia
```
✅ Armonía: Claramente secuencial (Primero → Segundo → Tercero)

### **Para OTROS Enfoques (No Expositivos)**

Los patrones tradicionales aplican:

### **Patrones Comunes:**

#### **1. Problema → Solución → Aplicación**
```
I. El Desafío de la Unidad en la Iglesia
II. Cristo: El Modelo Supremo de Humildad
III. Viviendo la Kenosis en Comunidad
```

#### **2. Pasado → Presente → Futuro**
```
I. La Gloria Preexistente de Cristo
II. La Humillación Voluntaria en la Cruz
III. La Exaltación Venidera de Todo Creyente
```

#### **3. Observación → Interpretación → Aplicación**
```
I. El Himno Cristológico de Pablo
II. La Naturaleza de la Kenosis Divina
III. Imitando el Patrón de Cristo Hoy
```

### **Verificación de Flujo:**
- ¿Cada punto lleva naturalmente al siguiente?
- ¿Se puede seguir la lógica sin saltos abruptos?
- ¿El último punto concluye/climax la proposición?

## ✅ Criterios de Calidad

Un bosquejo excelente:

### **ESTRUCTURA**
- [ ] 2-4 puntos (no más, no menos)
- [ ] Todos los títulos en el mismo nivel gramatical
- [ ] Progresión lógica clara

### **CONTENIDO**
- [ ] Cada punto desarrolla la proposición
- [ ] Descripciones específicas (no vagas)
- [ ] Referencias bíblicas pertinentes
- [ ] Balance entre exposición y aplicación

### **PREDICABILIDAD**
- [ ] Títulos memorizables
- [ ] Tiempo estimado: 10-15 min por punto
- [ ] Transiciones naturales
- [ ] Aplicaciones concretas distribuidas

### **TONO**
- [ ] Consistente con el enfoque seleccionado
- [ ] Apropiado para la audiencia
- [ ] Mantiene el espíritu del pasaje

## 🎨 Adaptación por Tipo de Enfoque

### **Expositivo/Didáctico**
- Títulos claros y estructurados
- Descripciones más detalladas
- Énfasis en "¿Qué dice el texto?"
- Más referencias cruzadas

**Ejemplo:**
```
I. Introducción al Contexto de la Exhortación (vv. 1-4)
   Exploración del imperativo paulino hacia la unidad...
   [Filipenses 2:1-4, Romanos 15:5-7]
```

### **Pastoral/Exhortativo**
- Títulos más cálidos y aplicados
- Descripciones orientadas a la vida
- Énfasis en "¿Cómo me afecta?"
- Balancear doctrina y ánimo

**Ejemplo:**
```
I. Nuestro Desafío Compartido: Abrazando la Mentalidad de Cristo
   En medio de las dificultades que enfrentamos como congregación...
   [Filipenses 2:1-4, Hebreos 10:24-25]
```

### **Evangelístico**
- Títulos accesibles y atractivos
- Descripciones orientadas a decisión
- Énfasis en "¿Por qué me importa?"
- Camino claro al evangelio

**Ejemplo:**
```
I. El Viaje de Cristo: De la Gloria al Sufrimiento por Ti
   La historia más extraordinaria de la historia...
   [Filipenses 2:5-8, Juan 1:1-14]
```

## 🔗 Integración con Aplicaciones Contemporáneas

Cada bosquejo debe incluir **3-5 aplicaciones totales** distribuidas:

### **Distribución Recomendada:**

```
Punto I:   1-2 aplicaciones
Punto II:  1-2 aplicaciones  
Punto III: 1-2 aplicaciones
```

### **Características de Buenas Aplicaciones:**
- ✅ Específicas (no vagas)
- ✅ Accionables (se pueden hacer)
- ✅ Relevantes (al contexto actual)
- ✅ Variadas (personal, familiar, eclesial, laboral)

**Ejemplo:**
```
"En lugar de promover nuestros logros en redes sociales, 
busquemos oportunidades esta semana para celebrar públicamente 
los éxitos de otros miembros de nuestra iglesia."
```

## ❌ Errores Comunes a Evitar

### **1. Puntos Desconectados**
❌ Cada punto parece un mini-sermón diferente
✅ Todos los puntos desarrollan la misma proposición

### **2. Títulos Genéricos**
❌ "I. Primer Punto"
❌ "I. Introducción"
✅ "I. El Desafío de la Unidad Cristiana"

### **3. Descripciones Vagas**
❌ "Este punto habla de la humildad"
✅ "Pablo contrasta dos mentalidades: buscar lo propio vs. el interés de otros, usando el verbo griego 'skopeo' para enfatizar observación intencional"

### **4. Falta de Referencias**
❌ Solo menciona el pasaje principal
✅ Conecta con 2-3 textos de apoyo

### **5. Sin Aplicación Práctica**
❌ Todo doctrina, cero aplicación
✅ Balance entre "¿Qué dice?" y "¿Qué hago?"

## 🎯 Aplicación por punto — UNA por punto

Cada punto del bosquejo lleva su propia aplicación, en el campo `application`.

### El orden es TEXTO → PUNTO → APLICACIÓN

La aplicación **se DERIVA del punto**, y el punto lo gobierna el texto. La
aplicación **NO dirige la exposición: la recibe.**

Es el componente 5 de los 6 de un movimiento; el obligatorio es la explicación
exegética del propio pasaje. Escribir un punto "hacia" su aplicación sería
moralismo con pasos previos — exactamente lo que el descalificador global G3
nombra: *el predicador impuso su idea y usó el texto de excusa*.

### Se ancla contra DOS anclas que ya existen

1. **La condición real** que el pastor nombró en su estudio.
2. **El llamado a la acción de la proposición.** Si la proposición dice "tres
   verdades que debemos abrazar", la aplicación de cada punto es cómo se abraza
   ESA verdad. Así la aplicación hereda el llamado igual que el título del punto.

Esto mata el llamado genérico por construcción: una aplicación que serviría para
cualquier sermón no está anclada a ninguna de las dos.

### Criterio

- **Una por punto.** No se rellena hasta un número ni se reparten "a lo largo
  del bosquejo": cada punto tiene la suya y se sabe cuál es.
- Específica y accionable (ver la guía de aplicaciones).
- **Si un punto no rinde aplicación propia, el problema es el punto**, no la
  aplicación: probablemente no está aterrizando nada.

```json
        "title": "I. [Título impactante en tono apropiado]",

        "scriptureReferences": [
          "[Pasaje principal]",

          "[Texto de apoyo 2 opcional]"
        ],
        "application": "[La aplicación de ESTE punto — ver § Aplicación por punto]"
      },
      {
        "title": "II. [Segundo título que fluye del primero]",
        "description": "[Desarrollo que avanza la progresión]",
        "scriptureReferences": ["..."],
        "application": "[La aplicación de ESTE punto]"
      },
      {
        "title": "III. [Título conclusivo/climático]",
        "description": "[Cierre que culmina la proposición]",
        "scriptureReferences": ["..."],
        "application": "[La aplicación de ESTE punto]"
      }
    ]
  }
}
```
