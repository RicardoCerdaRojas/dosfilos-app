## Atención al contexto

> **Atención:** Un error común es limitar el uso de las distintas formas a solamente una o dos opciones.
>
> Por ejemplo, el tiempo presente en griego no siempre indica una acción continua o progresiva; los autores tenían la libertad de usarlo también para acciones instantáneas.
>
> Conocer estas variaciones sintácticas es crucial para una exégesis precisa.
